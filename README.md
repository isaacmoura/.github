# .github

Arquivos de processo padrão da organização **isaacmoura**, herdados por todos os repositórios que não têm os seus:

- `ISSUE_TEMPLATE/` — formulários de issue (Bug, Feature, Customização de cliente, Tarefa técnica);
- `PULL_REQUEST_TEMPLATE.md` — modelo de pull request;
- `CONTRIBUTING.md` e `SECURITY.md`;
- `workflow-templates/` — modelos de workflow do GitHub Actions.

Este é o único repositório público da org (o GitHub exige isso para os padrões valerem). Não coloque aqui código,
dados ou qualquer informação interna.
